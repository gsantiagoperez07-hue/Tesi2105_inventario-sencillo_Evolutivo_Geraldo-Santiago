# Inventario Sencillo

## Problema que atiende
Este programa permite registrar un producto, su cantidad disponible y su precio.Calcula el valor total del inventario utilizando la cantidad y el precio del producto.

## Usuario Principal
Esta dirigido a una persona que necesita llvar un control basico de productos e inventario.

## Descripcion
El programa solicita al usuario el nombre dee un producto, la cantidad disponible y su precio.
Luego realiza un calculo para obtener el valor total del inventario. Finalmente, muestra la informacion del producto y el resultado del calculo de forma clara.
