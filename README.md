# Inventario Sencillo

## Problema que atiende
Este programa permite registrar un producto, su cantidad disponible y su precio.Calcula el valor total del inventario utilizando la cantidad y el precio del producto.

## Usuario Principal
Esta dirigido a una persona que necesita llvar un control basico de productos e inventario.

## Descripcion
El programa solicita al usuario el nombre dee un producto, la cantidad disponible y su precio.
Luego realiza un calculo para obtener el valor total del inventario. Finalmente, muestra la informacion del producto y el resultado del calculo de forma clara.

## Funcionamiento del proyecto final

Clase Producto: Guarda el nombre, la cantidad y el precio.
Calculo del inventario: Multiplica la cantidad por el precio.
Validaciones: Evita cantidades y precios negativos, y detecta entradas numericas incorrectas.
Estado del producto: Indica si esta aagotado, quedan pocas  unidades o hay inventario disponible.
Ciclo while: Permite registrar varios productos.
Finnalizarcion: El usuario puede escribir "no" para terminar el programa.

## Pruebas realizadas

Se probaron productos disponibles, agotados, cantidades bajas, numeros negativos y entradas incorrectas.

El programa repondio correctamente en las pruebas realizadas.

## Requisitos 

Tener Python 3 instalado en la computadora.
No necesita bibliotecas externas.

## Instrucciones de uso 

1. Descargar el archivo programa_personal.py.
2. Abrir una terminal en la carpeta del archivo.
3. Ejecutar: python programa_personal.py
4. Escribir el nombre, cantidad y precio del producto.
5. Revisar el resultado del inventario.
6. Escribir "no" para finalizar.

## Ejemplo de uso

Producto: Lapiz
Cantidad: 10 
Precio: 2.50
Valor total del inventario: $25.00
Estado: Inventario disponible.
